# Kopia wersji: Wersja początkowa (Portret kobiecego światła)
Zapisana: 2026-10-12

Ta wersja zawiera:
- Koncepcję Manufaktury Dubiński (od 1971 r.): drewno i światło
- Pełen soundscape audio z ambientem pracowni stolarskiej
- Trójwymiarową drewnianą ramę dębową z łączeniami na jaskółczy ogon
- Sekcje: Hero, Etapy powstawania dzieła, Dwa rzemiosła, Przymiarka w skali wnętrza, Formularz zamówienia dzieła

Pliki w tym folderze:
- index.html
- src/styles/index.css
- src/scripts/main.js
- src/scripts/content.js
- src/scripts/soundscape.js
